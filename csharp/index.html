02 / Logic and state

Chromble

Play the released game ↗

A standalone C# puzzle core: rules and state changes are separated from animation, sound and UI.

Separation of concerns
BoardModel handles placement, gravity and connected groups. BoardResolver computes cascades; presentation receives results through events.
State correctness
Preview calculations do not change the live board. Placing the next piece waits until the cascade ends, even if the player has already picked it up.
Selection algorithm
SpawnDirector considers board occupancy and valid placements. When space runs short, it selects a shape, color and position to clear blocks.

03 / Algorithms and data structures

Voxel
Pathfinding

Source on GitHub ↗

An adaptive voxel grid: spatial subdivision, a graph of free cells and route search.

Data representation
Cells intersecting geometry split into eight children. Face connections form a navigation graph.
Trade-offs
Cell size determines precision and graph size. The current implementation stores open nodes in a list sorted on each step, a limitation as the search grows.
