02 / UNITY · C# · 2D puzzle

Chromble

Personal project · Solo developer

Simple moves. Cascading consequences.

An 8 × 8 color puzzle: place a piece, connect six matching blocks and let gravity trigger the next cascade.

Game logic
Game rules live in a separate C# core. Animation, sound and UI receive the results through events.
Adaptive generation
The generator considers both occupied cells and valid placements, favoring useful pieces when space runs short.
Play on Yandex Games
Inside the game logic +

BoardModel handles placement, gravity and connected color groups. BoardResolver computes the cascade sequence; effects and sound follow its events.

  1. Evaluate the board
  2. Choose a shape and color
  3. Resolve the cascade

When space runs short, SpawnDirector favors pieces with more valid placements or searches for a shape, color and position that clears more blocks. Piece selection responds to the shape of the free space, not just its area.

The next piece can be picked up during a cascade, but placement waits until the board settles. Preview calculations do not change the live board.

03 / Engineering notes

A closer look at the systems.

01 / Spatial algorithms

Voxel
Pathfinding

Source on GitHub

An adaptive voxel grid for 3D navigation. Cells intersecting geometry are subdivided; free cells form a graph for route search.

  1. Subdivide space
  2. Build the graph
  3. Refine the route
Representation and trade-offs +

Subdivision creates eight child cells with face-based adjacency. Route processing uses intersections with cell faces before the demo agent follows a smoothed path.

Cell size trades geometric precision against graph size. The current search keeps open nodes in a list and sorts it at each step.

02 / Network states

Socket.IO
Networking

Source on GitHub

A Unity synchronization layer with RPCs, network variables and transform snapshots. Updates are batched into ticks; buffered states let remote objects move between network updates.

  1. Collect changes
  2. Send on a tick
  3. Interpolate states
Synchronization & interpolation +

Attributes register RPCs; generic network variables define state. HostToClient, ClientToHost and Both control update direction, while Calm and Forced distinguish sending modes.

Interpolation plays back states with a short delay, keeping neighboring snapshots in the buffer to calculate the position between them. Smoother motion comes at the cost of that delay.

The client requires the paid Best Socket.IO transport and a separate server, which is not included in the repository. Prediction and reconciliation are outside the implemented feature set.
