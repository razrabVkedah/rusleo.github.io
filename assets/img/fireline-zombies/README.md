# Fireline: Zombies screenshots

Игровые скриншоты для кейса и галереи Fireline: Zombies.

Шесть актуальных кадров: `combat.webp`, `building.webp`, `arsenal.webp`,
`modifiers.webp`, `missions.webp` и `scope.webp` (1600×900).

На странице показаны бой и уменьшенные превью строительства и арсенала
(`building-thumb.webp`, `arsenal-thumb.webp`, 640×360). Остальные полные кадры
загружаются при открытии галереи. Все изображения сохранены без обрезки.

Исходные PNG находятся в игнорируемой папке `_temp/zombie` и не изменены.
Старая серия скриншотов удалена из рабочей копии и доступна в истории Git.
